# UZEBİM Asistan

YDÜ öğrenci sistemi (UZEBİM/DEBİM) için yeniden tasarım + akademik danışman chatbotu +
Google Maps konum bağlantılı kampüs rehberi.

## Rapor
- `rapor/surum1.md` — Sürüm 1 metni (düzenlemeyi burada yapın)
- `rapor/surum1.docx` — Teslim edilecek Word dosyası
- `rapor/md_to_docx.py` — Markdown'dan Word üretir:
  `pip install python-docx && python rapor/md_to_docx.py rapor/surum1.md rapor/surum1.docx`
